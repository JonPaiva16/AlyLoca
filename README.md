AlyLoca
🚗 Sistema de Locação de Veículos - FastAPI

Este projeto foi desenvolvido como parte do trabalho acadêmico orientado pelo Professor Alysson, com o objetivo de aplicar os conceitos de desenvolvimento de APIs modernas utilizando o framework FastAPI.

📘 Sobre o Projeto

O sistema de locação de veículos foi criado para simular o funcionamento de uma locadora, permitindo o gerenciamento de clientes, veículos e locações de forma simples e eficiente.

A API oferece endpoints para cadastrar, consultar, atualizar e remover informações relacionadas a cada entidade, além de permitir o controle das locações (quem alugou, qual veículo, por quanto tempo etc).

🧩 Funcionalidades

Cadastro de veículos (modelo, marca, ano, placa, status de locação);

Cadastro de clientes (nome, CPF, telefone, e-mail);

Registro de locações (cliente, veículo, datas de início e fim, valor total);

Controle de devoluções e atualização automática do status do veículo;

Documentação automática da API com Swagger e ReDoc.
